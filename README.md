# Focus & Move

Crie um aplicativo web em React com Tailwind CSS chamado 'ErgoPomodoro'. O aplicativo deve ter um design limpo e focado em saúde no home office, contendo: 1) Um timer central de Pomodoro (25 minutos de foco e 5 minutos de pausa ativa); 2) Um painel que, quando o timer de pausa é acionado, exibe um card interativo com um exercício laboral ilustrado para aliviar a tensão de quem trabalha sentado (com título, passos curtos e timer de 5 min regressivo); 3) Uma aba secundária 'Agente Personal' com um campo de chat simples onde o usuário pode digitar seus objetivos físicos e receber sugestões automáticas de metas e rotinas de movimento.
